Power Manifold checks for new firmware once a day and installs new
releases by itself. You can also install a release yourself as soon as it
is out, put automatic installs off, or turn them off.

## Automatic updates

When the controller finds a new release, it waits a random 1 to 7 days and
then installs it between 03:00 and 05:00 local time. The wait spreads each
release over a week, so a release with a problem can be withdrawn before it
reaches most controllers. Set the local time with **UTC offset** in the web
interface's **Settings**. Until the controller has the time from its time
server, it installs a release once the wait is over, at any hour.

**Your ports stay on** during an automatic update, the same as during one
you start. See [What happens during an update](#what-happens-during-an-update).

While a release is waiting, the web interface's **Settings** shows when it
will install, with two buttons:

- **Postpone 7 days** holds back automatic installs for a week. Press it
  again to postpone further.
- **Skip this version** stops this release from installing by itself. The
  next release installs as usual.

Home Assistant has the same two buttons, **Postpone update 7 days** and
**Skip this update**. **Install** works in either case. The **Skip** on
Home Assistant's update card only hides the update in Home Assistant; see
[Skipping an update](/guide/home-assistant/#skipping-an-update).

If an update fails its trial and the controller goes back to the previous
firmware, that release is not installed automatically again. You can still
install it yourself.

### Turning automatic updates off

Set **Automatic updates** to **Off** in the web interface's **Settings**, or
turn off the **Automatic updates** switch in Home Assistant. The controller
still checks once a day and shows new releases, and installs one only when
you start it. The setting is `update_auto` in the
[HTTP API](/integrations/http-api/#settings-keys), and `update auto off`
followed by `save` at the console.

## Installing an update yourself

When a new release is out, Home Assistant's **Firmware update** entity
shows *update available*. Press **Install**.

The web interface shows it too, on the status line and in the first row of
**Settings**. Press **Install** there. **Check for updates** asks right
away instead of waiting for the daily check.

You can also install with the
[HTTP API](/integrations/http-api/#installing-an-update).

## What happens during an update

<Steps>

1. **The new firmware downloads** next to the one that's running. The
   running firmware is kept.

2. **The controller restarts** into the new firmware. **Your ports stay
   on.** Devices keep their power while the controller restarts.

3. **The new firmware is on trial.** It must run properly for ten seconds
   and connect to the network. Then it becomes the installed version.

4. **If it doesn't,** the controller goes back to the previous firmware by
   itself, with your settings as they were. If it fails within ten minutes
   or restarts unexpectedly, it reverts too.

</Steps>

While the controller restarts, the blades keep running with the limits they
had and their own protection. Power sharing and fault handling resume once
the controller is back, after a few seconds. Devices that are plugged in
keep the power they had: the controller sends them no new offer unless the
budget no longer covers them.

## Blade firmware

The blades have their own firmware, and the controller carries the version
that goes with it. You don't need to do anything. After a controller update
the controller brings each blade up to date by itself, but only when its
port is not in use:

- when the chassis is switched on, before the port powers up;
- when its port has had nothing plugged in for ten seconds.

**A port that is powering a device is never interrupted for a blade
update.** It waits until the device is unplugged, which could be days for a
Raspberry Pi. Updating a blade takes a few seconds. Its light is off while
it happens, and its state shows `updating` with a percentage.

## Security

Every release is signed. The controller only installs firmware that is
signed by this project, built for this hardware, and not older than what
it is running. Because of that, the download doesn't need to be encrypted.
Updates come from `fw.powermanifold.io`, which serves the project's GitHub
releases.
