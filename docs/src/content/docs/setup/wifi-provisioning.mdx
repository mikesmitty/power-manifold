Power Manifold gets its Wi-Fi details over a short-range wireless link,
using the [Improv Wi-Fi](https://www.improv-wifi.com/) standard. You can do
it from this page or from the Home Assistant app. The setup runs in your
browser and connects directly to the controller, so your Wi-Fi password is
sent only to the controller. Your phone or computer must be near the
chassis.

<ImprovProvisioner />

<Aside type="note" title="Which browser?">
This page works in Chrome and Edge on desktop and Android. It does not work
in Safari or Firefox, or in any browser on an iPhone or iPad. On those, use
the Home Assistant app: go to **Settings → Devices & services → Add
integration** and search for **Improv**. The app also shows a
notification by itself when it finds a Power Manifold waiting for setup.
Either way, open `http://pwrman.local/` afterwards to finish setup.
</Aside>

## Steps

<Steps>

1. **Turn it on.** A controller with no Wi-Fi details starts waiting for
   setup by itself about 15 seconds after power-up, unless it is already on
   the network over Ethernet. The chassis light, left of port 1, breathes blue while
   it waits.

2. **Connect.** Press the button above. Your browser lists nearby devices
   waiting for setup. Pick Power Manifold.

3. **Identify it (optional).** If you have more than one, press
   **Identify**. The port lights on that one flash blue.

4. **Enter your Wi-Fi name and password.** The controller joins your
   network. If the password is wrong, or the controller gets no address
   within 30 seconds, you'll see *unable to connect* and can try again.

5. **Press Next.** When it says *Provisioned!*, press **Next**. It opens the
   controller's web interface. On a new controller the settings stay open
   to anyone on your network for ten minutes, so you can finish
   [first-time setup](/setup/first-time-setup/#steps) by choosing an API
   token. If **Next** is not offered, go to `http://pwrman.local/`.

</Steps>

## Changing Wi-Fi later

The controller's setup link is open only while it is waiting for setup.
It starts waiting by itself when it has no Wi-Fi details, or when it has
been off the network for five minutes. To change networks on a controller
that is working, open a ten-minute setup window in either of these ways:

- Hold the front-panel button for 3 seconds, then let go before 10 seconds.
  See [the button](/guide/front-panel/#the-button).
- Press **Open Wi-Fi setup** in Home Assistant.

Then follow the steps above. The setup link is off at all other times.

<Aside type="caution">
The setup link is not encrypted. Run setup only when no untrusted person
is near the chassis.
</Aside>
