If you use Home Assistant, you don't need this page: see
[Home Assistant](/guide/home-assistant/). This page is for
Node-RED, scripts and other MQTT tools.

Set the broker in the web interface's **Settings**. Every topic starts with
`pwrman/<name>/`, where `<name>` is the device name (`pwrman` by default).
Ports are numbered 1 to 6.

## What it publishes

| Topic | When | Contents |
| --- | --- | --- |
| `availability` | retained | `online`, or `offline` when the controller disconnects |
| `status` | every second, retained | the whole chassis, see below |
| `port/<n>/telemetry` | every second | one port, see below |
| `event` | on each event | `{"port", "event", "kind", "code", "arg", "text", "ts"}` |
| `update/state` | retained | `installed_version`, `latest_version`, `release_url` (the release notes), `in_progress` and `update_percentage` (0–100 while an update downloads, else `null`) |
| `update/auto` | retained, on change | `ON` or `OFF`: whether new releases [install automatically](/guide/updates/#automatic-updates) |
| `blades/state` | retained, on change | `installed_version`, `latest_version` and `release_summary` for the blades: the installed version differs while a [blade update](/guide/updates/#blade-firmware) waits |

**`status` fields:** `total_w`, `reserved_w`, `budget_w`, `headroom_w`,
`energy_kwh`, `fan`, `fan_mode`, `alert`, `rssi`, `uptime_s`, `led`,
`led_mode`, `fw`, `boot` (why it last started), `problem` and `problems`,
`charged_mw`, `charged_min`, the input voltage `vin_v` (`vin` is false
when it isn't measured), and `ceiling_w` (60 while [low input voltage caps
the ports](/guide/troubleshooting/#ports-capped-at-60-w),
else 0).

**`port/<n>/telemetry` fields:** `state`, `gen` (blade generation), `v`,
`i`, `p`, `e` (kWh), `contract_w`, `pdo`, `contract` (`fixed`, `pps`,
`avs`, or `null` without a contract), `prio`, `limit_w`, `max_v`,
`boot`, `charged`, `auto_off`, `sleep_min`, `fault`, `last_fault`,
`last_fault_at`, the blade temperatures `t_conv`, `t_plug` and `t_mcu` in
°C (`null` when there's no reading), `progress` (0–100 during a blade
update), `update_due` (a blade update is waiting), `fw` (the blade's
firmware version, `null` when unknown) and `silent`.

**Events:** `kind` is one of the
[Home Assistant event types](/guide/home-assistant/#automations).
`text` explains faults, auto-off, USB-C® resets and blade updates. Chassis events, such as
the input voltage crossing its low warning, use port 0.

## Commands

Publish to these topics to send commands or change settings. Settings changed over MQTT are
saved a few seconds after the last change.

| Topic | Payload |
| --- | --- |
| `port/<n>/set` | `ON`, `OFF`, `hard_reset` or `src_cap` (re-announce) |
| `port/<n>/priority/set` | 0–255, 0 = most important |
| `port/<n>/limit/set` | power limit in watts, 5–100 |
| `port/<n>/volt/set` | voltage cap: `5`, `9`, `12`, `15` or `20` |
| `port/<n>/boot/set` | power-up state: `on`, `off` or `last` |
| `port/<n>/autooff/set` | switch off once charged: `ON` or `OFF` |
| `port/<n>/sleep/set` | sleep timer in minutes, 0 = off |
| `budget/set` | chassis budget in watts |
| `fan/set` | `auto`, `on` or `off` |
| `led/set` | light brightness, 0–255 |
| `charged_mw/set`, `charged_min/set` | when a device counts as charged |
| `improv/set` | `open`: open Wi-Fi setup for ten minutes |
| `update/set` | `install`: install the newest known release; `check`: ask for a new release now instead of at the daily check; `postpone` or `skip`: hold back [automatic installs](/guide/updates/#automatic-updates) for 7 days, or for the release now offered |
| `blades/set` | `install`: update every blade whose update is waiting now; their devices lose power for a few seconds |
| `update/latest` | retained pointer `{"version":"x.y.z","url":"http://…/controller.signed.bin"}` to offer your own release source. The controller uses the newer of this version and the one found by the daily check. |

Example, with Mosquitto's command-line client:

```sh
mosquitto_pub -h broker.lan -t pwrman/pwrman/port/3/set -m OFF
```

The broker is trusted: anyone who can publish to these topics can control
the ports. Use your broker's access control to limit who can.
